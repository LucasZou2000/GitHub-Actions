# Synthetic calibration set — NOT real gait data

100 windows of shape `[2, 12, 1, 264]` float32, generated by `tools/make_calib.py`
with a fixed seed. They exist so `hb_mapper makertbin` can produce a `.bin` and
real board latency can be measured.

**Any accuracy number obtained from a model calibrated with this set is meaningless.**
The `.bin` is named `nature_bpu_synthcal` for the same reason.

Real calibration must come from recorded trials (`<subject>_<trial>_exo.csv`,
200 Hz, 249-frame windows) pushed through the same pipeline described in
`models/preprocess.json`.
