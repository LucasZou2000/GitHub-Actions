结论

① Q8 @200 Hz 达标：BPU 单帧 0.75 ms（内核纯硬件 0.68 ms、FPS 1461），端到端 p99 0.90 ms、max 5.79 ms，60 000 帧中 0 帧越过 45 ms 期望线；进程 CPU 仅 8.6%（0.09 核）。
② FP32 50 Hz 结构性不达标：最快配置 14.2 ms/帧、3.6 核、端到端 p99 31.9 ms、max 74.5 ms（31 帧越 45 ms）；最省 CPU 配置 2.4 核，但单帧 18.1 ms、1456 帧越线；8 线程自旋在满载下互相抢核，端到端 p99 崩到 116 ms，34858 帧越线、8551 帧越 75 ms 硬限。
③ 精度可用：相对误差 5.3%（各关节 4.6–6.4%），绝对 p99 0.065、max 0.156 Nm/kg，余弦 0.9986、SNR 25.5 dB、|m|>0.1 方向一致率 100%，无系统偏差。
④ 结论：Q8 @200 Hz 是唯一同时满足延迟、抖动、CPU 余量与温度的方案；FP32 只保留作离线参考实现。
